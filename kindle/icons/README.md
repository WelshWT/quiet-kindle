Icons KOReader looks up by name check this folder first (`icons/<name>.svg` beats
`resources/icons/mdlight/<name>.svg`), so these replace KOReader's thin built-ins with the
Quiet set (rounded, 1.8 stroke) wherever KOReader or SimpleUI draws them: the library's search
and page arrows, dialog close, the hamburger menu, the classic menu's settings gear.
`quiet/` holds the tab-bar and Store-row icons SimpleUI is pointed at.
